# Blood in the Water

A Feral Druid addon for Cat Form. It adds its own energy bar, combo points, timers for important debuffs, and icons for key procs and cooldowns, all positioned exactly where you want them. It only shows up in combat while in Cat Form and stays out of the way otherwise.

## Features

- **Energy bar** for Cat Form
- **Combo point display** with a color per combo point count
- **Debuff timers** for your important DoTs, with a glow when it's time to refresh them early
- **Proc icons** for procs like Clearcasting
- **Cooldown icons** for cooldowns like Tiger's Fury and Berserk
- Shown only in combat while in Cat Form, hidden automatically otherwise — no manual toggling needed

## More

- **Config Mode** — shows everything at once with placeholder icons, so you can position it all without a target or active buffs
- **Custom look** — pick your own bar texture, border, and font; the addon's own ones are used again automatically if yours is no longer available
- **Profiles** — settings are saved in profiles that all of your characters can share, switch, copy, and reset
- Nothing else to install

## Configuration

Type `/bitw` to open the configuration dialog.

- **Energy Bar tab** — e.g. bar size, position, and texture
- **Combo Points tab** — e.g. text position, font size, and colors
- **Icons tab** — e.g. icon size and font shared by all icons
- **Debuffs tab** — e.g. icon positions and the refresh glow
- **Proccs tab** — e.g. icon positions and countdown color
- **Cooldowns tab** — e.g. icon position and spacing
- **Profiles tab** — manage your profiles
- **Toggle Config Mode** button (top of the dialog) — preview everything at once for positioning

## Known limitations

- Druid-only, Cat Form-only — by design, not a bug
- Supports Retail and WoW Forever. On WoW Forever Rake, Rip, Tiger's Fury, Berserk and Clearcasting are tracked; Moonfire, Predatory Swiftness, Incarnation, the combo point overflow buffer, the refresh glow and the Clearcasting stack count don't exist there
